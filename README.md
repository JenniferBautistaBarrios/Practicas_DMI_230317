## 📖 Descripción

Este repositorio contiene las prácticas desarrolladas durante la asignatura de **Desarrollo Móvil Integral (DMI)**, correspondiente a la carrera de Ingeniería en Desarrollo y Gestión de Software.

El objetivo es aplicar los fundamentos del desarrollo de aplicaciones móviles multiplataforma utilizando **Flutter** y el lenguaje de programación **Dart**. Durante el desarrollo de las prácticas se trabajan conceptos como la creación de interfaces mediante widgets, el manejo de estados, la interacción con el usuario y la integración de servicios externos mediante API.

Cada práctica incluye el código fuente, una descripción de las actividades realizadas y, cuando corresponde, evidencias del funcionamiento de las aplicaciones.

## 🛠️ Tecnologías utilizadas

- **Flutter:** framework para desarrollar aplicaciones multiplataforma.
- **Dart:** lenguaje de programación utilizado en Flutter.
- **Android Studio:** herramientas para ejecutar y probar aplicaciones móviles.
- **Visual Studio Code:** editor de código para desarrollar los proyectos.
- **Git:** sistema de control de versiones.
- **GitHub:** plataforma para alojar y administrar el código fuente.
